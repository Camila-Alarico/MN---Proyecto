CASO APLICADO

Demanda de tres servicios

Se miden tres cantidades agregadas que combinan la demanda de tres servicios. Las incógnitas \(x_1,x_2,x_3\) son índices normalizados de demanda, uno por servicio. El sistema es de tamaño \(n=3\): tres ecuaciones y tres incógnitas (el laboratorio admite \(n=2\) y \(n=3\)).

\[\begin{pmatrix}4&1&1\\1&5&1\\1&1&6\end{pmatrix}\begin{pmatrix}x_1\\x_2\\x_3\end{pmatrix}=\begin{pmatrix}9\\14\\21\end{pmatrix}\]
Verificación de la solución exacta \(x=(1,2,3)\)

\(4(1)+1(2)+1(3)=9\); \(1(1)+5(2)+1(3)=14\); \(1(1)+1(2)+6(3)=21\). Las tres ecuaciones se cumplen: el residuo \(r=b-Ax\) es cero.

MÉTODO DIRECTO

Eliminación gaussiana con pivoteo parcial

En cada columna \(k\) se elige como pivote el elemento de mayor valor absoluto entre las filas \(k,\dots,n\) y se intercambian filas si hace falta. Luego se anulan los elementos inferiores con los multiplicadores \(m_{ik}=a_{ik}/a_{kk}\). Al terminar, la sustitución hacia atrás obtiene \(x_n,\dots,x_1\).

\[x_i=\frac{c_i-\sum_{j>i}u_{ij}x_j}{u_{ii}}\]
{% include 'components/theory_animation.html' with scene='gauss' hint='Pivote, multiplicadores y sustitución hacia atrás sobre el caso base.' %}
Criterio de pivote problemático

El pivote es problemático si \(|\text{pivote}|<\varepsilon\cdot\max|a_{ij}|\), con el máximo sobre la matriz original. Con \(\varepsilon=10^{-12}\) el sistema se declara singular y no se calcula solución; con \(\varepsilon=10^{-6}\) se avisa de un pivote pequeño (posible pérdida de cifras). Ejemplo de fallo: filas \((1,2)\) y \((2,4)\) con \(b=(3,6)\); tras eliminar queda una fila nula y no hay solución única.

MÉTODO ITERATIVO

Gauss-Seidel

Cada incógnita se actualiza con los valores más recientes. Desde \(x^{(0)}=(0,0,0)\), tolerancia \(10^{-6}\) y máximo 100 iteraciones:

\[x_i^{(k+1)}=\frac{b_i-\sum_{j<i}a_{ij}x_j^{(k+1)}-\sum_{j>i}a_{ij}x_j^{(k)}}{a_{ii}}\]

Primera iteración del caso base: \(x_1=9/4=2.25\), \(x_2=(14-2.25)/5=2.35\), \(x_3=(21-2.25-2.35)/6\approx2.7333333\). En cada iteración se muestra el vector y el residuo \(\|b-Ax^{(k)}\|_\infty=\max_i|r_i|\). Se detiene cuando el paso y el residuo son \(\le\) tolerancia.

CONVERGENCIA

Dominancia diagonal: suficiente, no necesaria

Una matriz tiene dominancia diagonal estricta por filas si \(|a_{ii}|>\sum_{j\ne i}|a_{ij}|\). El caso base la cumple (\(4>2\), \(5>2\), \(6>2\)), y eso garantiza que Gauss-Seidel converge desde cualquier vector inicial. Pero es una condición suficiente, no necesaria:

SIN DOMINANCIA, CONVERGE

\(\begin{pmatrix}2&3\\3&6\end{pmatrix}x=(5,9)\) no es diagonalmente dominante, pero Gauss-Seidel converge a \((1,1)\) en unas 50 iteraciones.

EL ORDEN IMPORTA

Las mismas ecuaciones del caso base con las dos primeras filas intercambiadas pierden la dominancia y Gauss-Seidel diverge, mientras el pivoteo parcial resuelve el sistema sin problema.

Residuo y error no son lo mismo

Un residuo pequeño indica que las ecuaciones casi se cumplen, pero en sistemas mal condicionados puede haber un error grande en \(x\). Por eso se comparan ambos métodos y se examinan las advertencias.
