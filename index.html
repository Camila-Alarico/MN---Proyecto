Empezamos por los datos

Un sistema se representa como A · x = b: A contiene los coeficientes, b las observaciones conocidas y x las incógnitas.

Esta prueba recibe A y b, comprueba sus entradas y muestra los datos aceptados. Todavía no calcula la solución ni el residuo. La eliminación gaussiana con pivoteo parcial y Gauss-Seidel se implementarán en semanas posteriores.

1. Introduce el sistema

Completa todos los campos con números reales finitos. Usa punto para los decimales (por ejemplo, −2.5 escrito como -2.5). También se admite 1e-6.

Cambiar el tamaño deja los campos vacíos para un nuevo sistema.
