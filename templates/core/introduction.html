Métodos numéricos desde cero

Objetivo: convertir un problema en un modelo, calcular una aproximación e interpretar su error. Puedes recorrer los temas en cualquier orden y consultar la teoría durante la práctica.

1. Del problema al modelo

Un método numérico es un procedimiento de cálculo que aproxima una solución. Una solución analítica usa expresiones exactas; una numérica utiliza operaciones e iteraciones y necesita un criterio para detenerse.

Ejemplo: para encontrar cuándo una magnitud modelada por f(x) = x² − 2 se anula, buscamos una raíz. La solución positiva exacta es √2; una aproximación es 1.4142. Su error absoluto es aproximadamente 0.00001356.

2. Prerrequisitos rápidos

Funciones y derivadas
Una función asigna un valor f(x) a cada entrada. Su derivada mide la pendiente: si f(x) = x² − 2, entonces f′(x) = 2x. Newton usa esa pendiente para mejorar una estimación.
Integrales
Una integral definida representa acumulación o área con signo. Por ejemplo, la integral de x entre 0 y 1 vale 1/2.
Matrices y sistemas
Un sistema lineal se escribe A·x = b. En 2x + y = 5, x − y = 1, la solución es x = 2, y = 1. Sustituir ambos valores verifica las ecuaciones. Para una matriz 2×2, el determinante ad − bc debe ser distinto de cero para tener solución única.
Programación
Una variable guarda datos; un bucle repite una operación y una condición decide cuándo terminar. Limita siempre las iteraciones y comprueba divisiones entre cero.

3. Precisión y límites del cálculo

Punto flotante: la computadora representa números con una cantidad finita de bits. Algunas fracciones decimales no son exactas en binario; por eso 0.1 + 0.2 puede producir 0.30000000000000004.

Cifras significativas: expresan la precisión de un dato. 1.20 tiene tres cifras significativas. Conserva cifras adicionales durante el cálculo y redondea al presentar el resultado.

Taylor: aproxima una función cerca de un punto con sus derivadas. Alrededor de cero, exp(x) ≈ 1 + x + x²/2. Para x = 0.1, da 1.105; exp(0.1) ≈ 1.105170, con error absoluto aproximado 0.000170. El truncamiento omite los términos restantes.

Parada: un cambio pequeño entre iteraciones no garantiza por sí solo una raíz correcta. Comprueba también el residuo |f(x)|, el dominio y las condiciones de convergencia del método.

4. Un ejemplo paso a paso: bisección

Resolver x² − 2 = 0 en [1, 2]. La función es continua y f(1) = −1, f(2) = 2: hay cambio de signo.

  1. Punto medio: m = (1 + 2)/2 = 1.5. Como f(m) = 0.25, conservar [1, 1.5]. Cota del error de m: 0.5.
  2. Nuevo punto medio: m = 1.25. Como f(m) = −0.4375, conservar [1.25, 1.5]. Cota del error: 0.25.
  3. Nuevo punto medio: m = 1.375. Como f(m) = −0.109375, conservar [1.375, 1.5]. Cota del error: 0.125.

La cota es la mitad de la longitud del intervalo usado para calcular cada punto medio. Repetir reduce esa cota. El residuo mide cuánto falta para satisfacer la ecuación; es una medida diferente.

Si el valor de referencia es 10 y obtuviste 9.8, calcula el error absoluto y relativo.

Ver respuesta y explicación

Error absoluto: |10 − 9.8| = 0.2. Error relativo: 0.2/10 = 0.02; porcentaje: 2 %. Si la tolerancia absoluta es 0.1, la aproximación no cumple porque 0.2 > 0.1.
